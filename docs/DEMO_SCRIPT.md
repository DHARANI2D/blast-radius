# 5-minute demo video script

Setup: `python -m blastradius ui`, browser at 1500×950 or larger. In the sidebar: **Tool transport: mcp**, **Fault scenario: Canary regression (ROM + NIC 229.x, ~4x)**. Press **Reset lab** before recording; it also clears the planner's memory, so run 1 starts cold.

|---|---|---|
| 0:00-0:25 | Title slide, then the Control Tower | "41% of major network outages and 51% of major IT outages start with a change (Uptime 2026). Tonight an AI agent wants to upgrade 40 servers and two top-of-rack switches. Should you let it?" |
| 0:25-0:50 | Intent is pre-filled. Click **Analyse change**. Point at the agent timeline. | "BlastRadius parses the intent. Its Topology agent then builds a live dependency graph from five MCP servers in about a second: 563 nodes across compute, network, virtualization and storage." |

The constraint checker rejects the plan with 13 violations." |
| 1:15-1:55 | Tab ② Plan & Verifier: attempt 1, then attempt 2 | "Second catch: hallucinations. The planner claims 'ROM v2.32 remediates SYN-CVE-2026-1105' and rates itself 91% confident. That's about $64K avoided at illustrative, sourced rates. The ITIC $1.2M figure is shown only as a cross-check." |

| 4:40-5:00 | Tab ⑥ Ask (one question), Tab ⑤ Audit: **Verify chain**, **Simulate tampering**; architecture slide | "You can ask why. The answers come from read-only tool calls, and the Verifier checks them too. Every prompt hash, tool call, claim, approval and action goes into a hash-chained ledger; edit one entry and the chain breaks. BlastRadius is MCP-native and exposes an A2A endpoint. It's built to plug into GreenLake Intelligence as preventive runtime control for the agentic enterprise." |

Say plainly once in the video: *"Execution here runs against a simulated digital twin with injected faults. The data is synthetic, and the LLM is an offline stand-in unless an HPE-approved endpoint is configured."*

Tab ⑥ has one-click example questions: *Why is tor-r1-a the riskiest asset?*, *Does System ROM U54 v2.32 fix SYN-CVE-2026-1105?* (good for the video: the answer contradicts the planner's first draft), *How many hosts of PROD-BLR-07 can be in maintenance at once?*, *Tell me about blr-esx-07*. In offline mode a deterministic router picks the tools, so free-form questions outside these shapes get a generic answer.

Backup if the UI misbehaves: `python -m blastradius demo --auto-approve --reset` shows run 1 in the terminal. Run it again without `--reset` to show the deferred hosts and the memory-conditioned first draft.
